# 🎬 TeraPlayer – Online TeraBox Video Player & Downloader

iTeraPlay-এর মতো একটি আধুনিক, হাই-স্পিড এবং ১০০% কার্যকর ওয়েব অ্যাপ্লিকেশন যা ব্যবহারকারীদের যেকোনো TeraBox ভিডিও সরাসরি ব্রাউজারে দেখা এবং ডাউনলোড করার সুবিধা দেয় (কোনো অফিশিয়াল অ্যাপ বা সফটওয়্যার ছাড়াই)।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

- ⚡ **জিরো বাফারিং স্ট্রিমিং:** অ্যাডাপ্টিভ HLS (M3U8) এবং ডিরেক্ট প্রক্সি স্ট্রিমিং সাপোর্ট।
- 🎥 **প্রফেশনাল ভিডিও প্লেয়ার:** Plyr.js দিয়ে তৈরি আধুনিক প্লেয়ার—কোয়ালিটি কন্ট্রোল, প্লেব্যাক স্পিড, ফুলস্ক্রিন ও পিকচার-ইন-পিকচার (PiP) মোড সহ।
- 📥 **ডিরেক্ট ফাস্ট ডাউনলোড:** এক ক্লিকে সরাসরি ব্রাউজার দিয়ে ভিডিও ডাউনলোড করার সুবিধা।
- 🛡️ **CORS ও 403 Forbidden বাইপাস:** ভিডিও সার্ভ করার জন্য ব্যাকএন্ডে বিল্ট-ইন HTTP 206 Range Request প্রক্সি।
- 📁 **মাল্টি-ফাইল ফোল্ডার সাপোর্ট:** কোনো লিংকে একাধিক ফাইল থাকলে স্বয়ংক্রিয়ভাবে সব ফাইল তালিকাভুক্ত করে এবং প্রতিটিতে ক্লিক করে চালানো যায়।
- 🕒 **হিস্ট্রি ট্র্যাকিং:** ব্রাউজার `localStorage`-এ সাম্প্রতিক প্লে করা ভিডিও সেভ থাকে।
- 🔑 **NDUS কুকি সাপোর্ট:** TeraBox-এর ক্যাপচা ও রেট লিমিট সম্পূর্ণ বাইপাস করার জন্য সেশন কুকি ইনপুট নেওয়ার ব্যবস্থা।

## 🚀 কীভাবে চালু করবেন (How to Run)

প্রজেক্ট ডিরেক্টরিতে প্রবেশ করে নিচের কমান্ড দিয়ে সার্ভার রান করুন:

```bash
# ডিপেন্ডেন্সি ইনস্টল (ইতিমধ্যে করা আছে)
pnpm install

# সার্ভার চালু করুন
pnpm start
```

সার্ভার চালু হওয়ার পর আপনার ব্রাউজারে প্রবেশ করুন:
- **Local:** `http://localhost:3000`
- **Network (একই ওয়াইফাইয়ের অন্য ডিভাইসে):** `http://<YOUR_IP>:3000`

## 🔑 ১০০% নিশ্চিত পারফরম্যান্সের জন্য TeraBox `ndus` কুকি কীভাবে পাবেন?

কোনো ক্যাপচা বা ব্লকিং ছাড়া সবসময় হাই-স্পিড ডাউনলোড ও প্লে করতে:

1. যেকোনো ব্রাউজারে (কম্পিউটার বা মোবাইলের ব্রাউজার যেমন Kiwi/Chrome) [terabox.com](https://www.terabox.com)-এ একটি ফ্রি অ্যাকাউন্টে লগইন করুন।
2. কিবোর্ডে `F12` চাপুন (অথবা রাইট ক্লিক করে **Inspect** সিলেক্ট করুন)।
3. **Application** (বা Firefox-এ **Storage**) ট্যাবে যান।
4. বাম পাশের মেনু থেকে **Cookies** &rarr; `https://terabox.com` সিলেক্ট করুন।
5. সেখানে **`ndus`** নামের কুকিটি খুঁজে পাবেন। এর **Value** কপি করুন।
6. TeraPlayer ওয়েবসাইটের উপরের ডানদিকের **Settings** আইকনে ক্লিক করে পেস্ট করে **Save** দিন (অথবা সরাসরি প্রজেক্টের `.env` ফাইলে `TERABOX_NDUS=আপনার_কুকি` লিখে সেভ করুন)।
